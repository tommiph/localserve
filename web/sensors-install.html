Sensors

Android 8.0 or later

Download Android APK
  1. Open this page on Android, download the APK and open the downloaded file. Allow installation from your browser if Android asks.
  2. Enable the Sensors plugin in Localserve.
  3. Enter this server address in the Android app, choose your sensors or phone events and tap Start. Grant access for your selected sources when Android asks.

Devices appear automatically in Sensors. Configure per-device Task rules in Tasks. Stop streaming from the app or its notification.

Location and named regions run during explicit streaming. Activity transitions require Google Play services. Install updates over the existing app to retain its device identity and settings.

Reports use the local network without pairing credentials. Sampling and reporting rates can differ; each report contains the latest raw sensor values. Sensor availability depends on the Android device and granted permissions.
