Controller

Android 8.0 or later

Open Downloads
  1. Open this page on Android, download the APK and open the downloaded file. Allow installation from your browser if Android asks.
  2. Open Controller → Settings, enter the server address below and tap Connect while on your home network. Approved relay details are retrieved automatically.
  3. Use the bottom Lights, Tasks, Remotes and Cards tabs. Content is configured in the server administrator; no profile files need to be copied.

Optional phone reporting: enable the Sensors plugin, open Settings → Phone reporting in Controller, select sources and tap Start. Grant access only for your selected sources. Devices appear automatically in Sensors. Stop reporting from the app or its notification.

Keep your server running. Full remotes and Cards require LAN; approved lighting scenes and Tasks can use the Google relay away from home. Use an up-to-date Android System WebView. Install over the Sormus phone-reporting app to retain its device identity and settings.

Reports use the local network without pairing credentials. Sampling and reporting rates can differ; each report contains the latest raw sensor values. Sensor availability depends on the Android device and granted permissions.
