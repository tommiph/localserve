Connection

Press OK to edit an address field. The shared display uses /display. You can also enter a Vista path such as /vistas/living-room.

Channel Up opens settings. Play/Pause controls supported content. Back closes the app; Left/Right changes Vista Card collections.

Live TV / HDMI

Select a connected video source.

Show video selects this TV input over the current Vista. Use the remote for volume. Installed streaming apps cannot appear in this window.

Channel Up opens settings and hides the video. Back closes the app. Notices, page changes and leaving also hide video. Show it again when needed.

Up/Down moves between controls. Left/Right changes the selected option.
