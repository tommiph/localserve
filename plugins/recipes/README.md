# Recipes

Open **Recipes → Create**, then enable Recipes if prompted. Pick an idea from
the floating cloud, or choose **Explore all ideas** to search everything your
configured devices can do. There is no need to choose a plugin first.

1. Choose what you want: a lighting mood, TV message, video, page or another
   available action. The choices come from your installed plugins.
2. Make it yours. Pick a named scene/device, write a message or adjust its value.
   Less common settings are under **More options**.
3. Choose when: a manual tap, a weekly time, a device signal, a countdown, an
   interval, sunrise or sunset. Sun times require your server location.
4. For a signal, search for the actual device/sensor/source. Choose every
   occurrence or a property to check, such as ambient light **is below** 20 lux
   or a video title **includes** a word.
5. Review your sentence and name it. Tap either highlighted phrase to edit it;
   your other choices stay in place. **Create task** saves the Task turned off.
   Open **Tasks** and enable it when ready.

For multiple actions, additional rules or Event values, expand **Want to go
further? → Open detailed editor** before creating. This opens an unsaved draft
in the normal Task editor. Created Tasks can also be edited there at any time.

The floating choices use bundled Material glyphs and local artwork. Use the
motion button to pause their movement; system reduced-motion preferences are
also honored. The wizard works with a keyboard and adapts to phone widths.

If an action is unavailable, configure its connection in that plugin's Settings.
If a light/app/scene is missing, check its connection and refresh its reported
list before reopening the recipe. Only real named choices are offered.

A matching reading condition starts a Task on the matching edge. A nonmatching
reading rearms it; it does not repeat continuously below a threshold. Occurrence
Events retain their normal baseline rules. Text includes is case-insensitive.
Timers and intervals count from rule enablement. Schedules use the server's
system timezone and its selected clock format.

Recipes uses fixed sentence choices, not AI or free-text interpretation. Friendly
wording preserves exact capability IDs and typed values behind the scenes.
Normal Task validation, readiness, pause, Do not disturb and overlap checks still
apply. Opening or composing a recipe does not save or run anything. Creation
requires the final button, and never enables or runs the new Task automatically.

Recipes owns its declaration, browser logic and scoped stylesheet. The host
provides public metadata, shared modal/discard protection and guarded Task saving;
no credentials or private settings are included in the catalogue. Installed
plugin JavaScript is trusted code, not a security sandbox. Disabling or removing
Recipes leaves created Tasks intact. It performs no background polling, provider
requests, synthetic Events or device commands. Fresh installations start off.
