# Sormus Downloads for Android

Install the APK from the PC's Downloads inbox plugin or **Downloads → Sormus Downloads**. Android 8 or newer is required. The package is `org.sormus.downloads`. It is separate from Controller and Sormus Go.

Pair using the PC's numeric private LAN address and the one-time eight-digit code from **Downloads inbox → Transfers → Pair a phone**. Select files or share them from another app. Magnet links and BitTorrent files may offer **Sormus Downloads** in Android's chooser. For web links that stay in a browser, use its Share command. Once paired, shared/opened files and torrent links start sending automatically and return to the originating app without opening the Downloads workspace. The foreground notification shows progress and cancellation. Launching Downloads normally still opens setup and the file picker; files chosen there use **Send to PC**. An unpaired incoming selection opens setup and sends after pairing succeeds. qBittorrent downloads torrent contents on the PC.

Uploads use a foreground notification with progress and cancellation. Use **Enable transfer notifications** in the app if Android notification permission has not been granted. Automatic received transfers do not interrupt sharing with a permission dialog. Up to eight further share batches wait in a bounded serial queue. Cancellation clears waiting batches, and interrupted work is never automatically redelivered. Each accepted batch retains the PC connection it was received for. Only explicitly selected content URIs are read; the app requests no broad storage or sensor permissions. Unknown-size provider files are copied into private cache within the configured server limit before upload. Connection credentials are stored privately with Android backup disabled. Use the PC's Disconnect button to revoke a phone; Forget this PC only removes its local copy.

Build with `runtime/node.exe plugins/downloads-inbox/android/build.mjs`. The pinned tools from `tools/android-build` must already be prepared. Normal builds do not download dependencies. Local signing keys stay under the build-tools private directory. The resulting APK is unconfigured and contains no address or pairing token. Source receipt, signature, alignment and address/link protocol tests are checked by the build. No phone is installed or controlled by this command.
