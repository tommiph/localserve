# Bundled plugins

All start disabled with fresh defaults. No live settings or saved Cards are included.

| Plugin | Setup | Ready-made design |
| --- | --- | --- |
| [adsb.lol](plugins/adsb-lol/README.md) | Nearby aircraft from adsb.lol public position reports | Airspace |
| [Calendar](plugins/calendar/README.md) | Subscribed calendars, agendas and Task reminders | Agenda |
| [Emby](plugins/emby/README.md) | Reported playback sessions from your Emby server | Screening room |
| [Finavia](plugins/finavia/README.md) | Finnish airport flight boards · Source: Finavia Public Flights | Departure lounge |
| [Fingrid](plugins/fingrid/README.md) | Finland electricity system datasets and latest readings | Grid |
| [HSL Trains](plugins/hsl-trains/README.md) | Finnish passenger train station boards · Source: Fintraffic / Digitraffic, CC BY 4.0 | Platform |
| [News](plugins/news/README.md) | Headlines from Google News RSS | Front page |
| [Oculus Go](plugins/oculus-go/README.md) | Wi-Fi headset diagnostics and a manual APK library | Orbital |
| [PC and Network](plugins/pc-network/README.md) | Windows CPU, GPU, memory, storage, adapters and network name lookups | Observatory |
| [PlayStation](plugins/playstation/README.md) | PSN presence, active game, playtime and trophies | Gaming lounge |
| [Recipes](plugins/recipes/README.md) | Build Tasks by choosing what you want and when it should happen | Ordinary Cards |
| [Samsung TV](plugins/samsung-tv/README.md) | Local Samsung TV readings, apps and remote controls | Home cinema |
| [Sensors](plugins/sensors/README.md) | Selected sensor and phone reports from trusted Android devices on the local network | Sensorium |
| [Simulator](plugins/simulator/README.md) | Local actions, values, and events | Signal lab |
| [TRÅDFRI](plugins/tradfri/README.md) | Legacy IKEA gateway lights, groups and lighting controls | Nordic |
| [Weather](plugins/weather/README.md) | Current weather from wttr.in | Atmosphere |
| [Webpage](plugins/webpage/README.md) | Embedded webpages, parsed text and page change events | Ordinary Cards |
| [YouTube](plugins/youtube/README.md) | Public channel uploads and new-video events | Studio |

Provider access, devices and your own credentials are separate from installing this server.
