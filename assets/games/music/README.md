# Game music

Place your looping background track here, then set its root-relative path under
Games → Neon Labyrinth → Edit, for example `/assets/games/music/maze.mp3`.
Supported file extensions are MP3, OGG, WAV and M4A; codec support depends on the
browser/TV. Keep tracks under 12 MiB. The game loads audio only when the player
enables Music, pauses it with gameplay and releases it when the page closes.
No track is bundled. User music is excluded from clean distributions.
